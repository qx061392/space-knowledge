# 航天知识库 - 微信小程序

一个面向全年龄段的航天科普知识库微信小程序，涵盖航天器与火箭、航天历史大事件、太阳系与深空探测、航天员与宇航员、航天基础知识五大板块。

## 功能特性

- **分类浏览**：5 大分类、45 篇科普知识，卡片式浏览体验
- **每日推荐**：每天精选一篇航天知识，日日有新知
- **全文搜索**：支持标题、摘要、标签、内容全文搜索，关键词高亮
- **趣味问答**：38 道随机题库，答题闯关+评级系统
- **收藏与历史**：一键收藏感兴趣的知识，自动记录浏览历史
- **深空主题**：沉浸式星空背景，渐变色彩，动画过渡

## 部署步骤

### 1. 安装微信开发者工具

前往 [微信官方文档](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html) 下载并安装对应平台的微信开发者工具。

### 2. 导入项目

1. 打开微信开发者工具
2. 点击「导入项目」
3. 项目目录选择本文件夹根目录
4. AppID 选择「测试号」或填入你自己的小程序 AppID
5. 项目名称可自定义（如"航天知识库"）
6. 点击「导入」

### 3. 本地预览

- 导入后，开发者工具会自动编译，在模拟器中即可预览完整功能
- 点击上方工具栏的「预览」可生成二维码，用手机微信扫码体验

### 4. 真机调试（可选）

- 点击「真机调试」，用手机微信扫描二维码
- 可在手机上完整体验所有功能

### 5. 发布上线

如需正式发布到微信小程序平台供他人使用：

1. 在 [微信公众平台](https://mp.weixin.qq.com/) 注册小程序账号
2. 在后台获取小程序 AppID
3. 将 `project.config.json` 中的 `"appid": "touristappid"` 替换为你的真实 AppID
4. 在开发者工具中登录管理员账号
5. 点击「上传」，填写版本号和备注
6. 在微信公众平台后台「版本管理」中提交审核
7. 审核通过后点击「发布」

## 内容说明

- 知识内容为科普性质，涵盖了世界航天史上的重要事件、代表性航天器、太阳系天体、著名航天员及航天基础知识
- 内容力求准确，但科普知识会随科学发展更新，建议定期维护
- 如需添加或修改内容，编辑 `data/knowledge.js`（知识条目）和 `data/quiz.js`（问答题目）即可，无需改动页面代码

## 数据格式

### 知识条目格式

```js
{
  id: 'sc001',              // 唯一ID（前缀代表分类）
  category: 'spacecraft',    // 分类：spacecraft/history/solar-system/astronauts/basics
  title: '标题',
  subtitle: '副标题',
  icon: '🚀',               // Emoji图标
  year: '1967',              // 相关年份（可选）
  tags: ['标签1', '标签2'],  // 标签数组
  summary: '一句话摘要',
  keyData: [                 // 关键数据（可选）
    { label: '高度', value: '110.6米' }
  ],
  content: '正文内容\n\n段落间用两个换行分隔'
}
```

### 问答题目格式

```js
{
  id: 'q001',
  category: 'spacecraft',
  difficulty: '简单',         // 简单/中等/困难
  question: '问题内容',
  options: ['选项A', '选项B', '选项C', '选项D'],
  answer: 0,                  // 正确答案索引（0-3）
  explanation: '答案解析'
}
```

## 技术说明

- 纯前端实现，无需后端服务器
- 数据内置在 `data/` 目录中，修改即可更新
- 使用微信小程序原生开发框架，无第三方依赖
- 收藏和历史使用 `wx.setStorageSync` 本地存储
- 支持 `v2` 样式和 `requiredComponents` 按需加载
