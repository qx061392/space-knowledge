# 航天知识库 - 自动更新系统

> 本系统由两部分组成：RSS定时拉取脚本 + opencode整理流程
> 拉取由cron定时自动执行，整理由你在对话中触发

---

## 系统架构

```
┌──────────────┐    cron定时    ┌──────────────┐    你说        ┌──────────────┐
│ RSS新闻源     │ ──────────→  │ fetch脚本     │ ──────────→  │ opencode整理  │
│ NASA/ESA/    │              │ 缓存到         │              │ 搜索补充→     │
│ Space.com   │              │ docs/news-cache│              │ 写入知识库     │
└──────────────┘              └──────────────┘              └──────────────┘
```

## 一、一次性设置（cron定时任务）

在你的电脑/服务器上设置定时任务：

### Linux / macOS（crontab）

```bash
# 编辑定时任务
crontab -e
```

添加以下行（根据需要选择频率）：

```cron
# 方案1：每天早上8点自动拉取
0 8 * * * cd /你的项目路径 && /usr/bin/node scripts/fetch-space-news.js >> docs/news-cache/fetch.log 2>&1

# 方案2：每周一早上8点拉取（推荐，避免信息过载）
0 8 * * 1 cd /你的项目路径 && /usr/bin/node scripts/fetch-space-news.js >> docs/news-cache/fetch.log 2>&1

# 方案3：每12小时拉取一次（适合热点追踪期）
0 */12 * * * cd /你的项目路径 && /usr/bin/node scripts/fetch-space-news.js >> docs/news-cache/fetch.log 2>&1
```

### Windows（任务计划程序）

1. 打开"任务计划程序"
2. 创建基本任务 → 名称"航天新闻拉取"
3. 触发器 → 每天/每周
4. 操作 → 启动程序
5. 程序：`node.exe`
6. 参数：`scripts/fetch-space-news.js`
7. 起始位置：你的项目路径

## 二、日常使用流程

### 第1步：脚本自动拉取（无需操作）
cron会在设定时间自动运行脚本，新文章缓存到 `docs/news-cache/` 目录。

### 第2步：你在opencode中触发整理
打开 opencode，输入以下任一指令：

> **"整理缓存的航天新闻"**
> 或
> **"更新知识库"**
> 或
> **"处理新闻缓存"**

### 第3步：opencode自动执行以下流程
1. 扫描 `docs/news-cache/` 中的新文章
2. 筛选有科普价值的重大新闻（过滤掉行业商业动态）
3. 对重要文章联网搜索补充细节
4. 按 `data/knowledge-new.js` 格式编写新知识条目
5. 编写配套问答题目到 `data/quiz-new.js`
6. 运行验证脚本确认数据完整性
7. 将已处理文章移至 `docs/news-cache/processed/`
8. 汇报新增内容清单

### 第4步：在微信开发者工具中预览
按 `Ctrl+B` 重新编译，即可看到新增内容。

## 三、手动操作命令

即使没有设置cron，你也可以手动操作：

```bash
# 手动拉取最新新闻
node scripts/fetch-space-news.js

# 拉取所有历史文章（不按日期过滤）
node scripts/fetch-space-news.js --all

# 查看已缓存的文章列表
node scripts/fetch-space-news.js --list
```

然后在 opencode 中输入"整理缓存的航天新闻"即可。

## 四、RSS源列表

当前监控的RSS源（可自行增删，编辑 `scripts/fetch-space-news.js` 中的 `FEEDS` 数组）：

| 源 | 语言 | 覆盖范围 |
|----|------|----------|
| NASA News | EN | NASA官方新闻发布 |
| Space.com | EN | 综合航天新闻 |
| SpaceNews | EN | 商业航天行业新闻 |
| ESA Top News | EN | 欧空局动态 |
| NASA Breaking News | EN | NASA突发新闻 |

### 添加中文RSS源（可选）
在 `FEEDS` 数组中添加：
```js
{ name: '中国航天网', url: 'http://www.spacechina.com/rss.xml', lang: 'zh' }
```
注意：中文RSS源需确认可访问性，部分国内站点可能需要翻墙或有访问限制。

## 五、整理时的筛选标准

并非所有缓存的新闻都值得写入知识库。整理时按以下标准筛选：

**值得写入的：**
- 重大发射事件（首飞、载人、深空探测）
- 新发现或科学突破（行星发现、望远镜成果）
- 里程碑事件（首次、最大、最远等）
- 技术概念科普（可重复使用、太空计算等）

**不写入的：**
- 商业合同和企业动态（XX公司获得XX合同）
- 行业市场报告（XX市场规模预测）
- 人员任命和人事变动
- 重复已有条目的内容

```
├── docs/

│   │   └── fetch.log           # 拉取日志
│   ├── 更新清单.md              # 内容更新清单
│   ├── 内容更新方法论.md         # 维护方法论
│   └── 自动更新指南.md          # 本文件
├── data/
│   ├── knowledge.js            # 原始知识数据
│   ├── knowledge-new.js        # 新增知识条目
│   ├── quiz.js                 # 原始问答数据
│   └── quiz-new.js             # 新增问答
```
